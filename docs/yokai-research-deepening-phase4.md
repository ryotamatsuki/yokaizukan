## Batch A — 輪入道 / 目目連 / 垢嘗

### 輪入道
鳥山石燕『今昔画図続百鬼』の個別原資料へ降りた。詞書に、車輪の轂に大きな入道の首がつき自ら巡ること、見る者が魂を失うこと、戸口へ「此所勝母の里」と書いた紙を貼る対処がある。炎は図像要素として扱い、攻撃能力にはしない。東洞院の片輪車との系譜は今回のA claimから外した。

### 目目連
鳥山石燕『今昔百鬼拾遺』の個別図像・詞書を確認。破れた障子の格子に多数の目が描かれる。碁打ちとの関係は石燕の見立てであり、確定した民俗由来にはしない。後世の「目を集めて売る」逸話は不採用。

### 垢嘗
石燕『画図百鬼夜行』の「垢嘗」は名と図像を直接確認できるが、個別詞書がない。一方『古今百物語評判』には「垢ねぶり」が古い風呂屋、塵垢の気、垢をなめる化生として記される。両者の同一性を原資料だけで確定できないため、Bを維持しLiterary Readyにはしない。

## Batch B — がしゃどくろ / 木霊

### がしゃどくろ
国芳『相馬の古内裏』の巨大骸骨図像と「がしゃどくろ」の名称を完全に分離した。NDLで江戸末期の巨大骸骨図像を確認。一方、市川寛也（2018）は1968年の水木しげる『日本妖怪大全』を、過去の国芳図像へ「がしゃどくろ」という固有名を与えた例として整理している。

1966年『別冊少女フレンド』の記事を初期例とする研究・解説は探索で確認したが、原誌本文を直接確保できなかった。したがって「1966年が初出」とは今回確定しない。分類B、Literary Ready=falseを維持する。

### 木霊
三系統を分離した。

1. 出版妖怪: 鳥山石燕『木魅』
2. 地域民俗: 徳島県三好郡の「木霊抜き」
3. 現代一般語・音響現象: こだま／山びこ

県史収録記録では、百年以上の古木を伐る際、小枝を切って他の木へ掛け渡す、または南天を植える具体的な木霊抜きが確認できる。これを直接scene anchorとしAへ再分類した。音を返す能力は追加しない。

## Batch C — 山姥

山姥は単独で監査し、最低3系統を分離した。

1. **出版図像系** — 鳥山石燕『画図百鬼夜行』の山姥。
2. **芸能系** — 日本芸術文化振興会・文化デジタルライブラリーで能『山姥』の継続上演を確認。芸能上の役を地域民俗へ移植しない。
3. **地域民俗系** — 静岡県史と愛媛県史の個別記録を採用。

静岡・倉木山では、家々で子守りや藤紡ぎを手伝う一方、ある家では子どもを食べる山姥が記録される。愛媛・久万高原では、正月の餅つきを手伝い、その餅を家業繁盛の福餅とする山姥が記録される。

この相反を「山姥は善悪両面の性格」と一人のキャラクターへ統合しない。次Literaryでは一系統だけを中心資料にする。候補は、場面が閉じており地域・行為・意味が直接資料だけで成立する**愛媛県史の餅つき系統**を第一候補とする。

## 採用しなかった主な資料

- Wikipedia単独、検索スニペット、出典不明まとめサイト: discoveryに限定。
- 現代妖怪辞典・商品ページ: 原資料への探索入口に限定。
- がしゃどくろ1966年初出説: 原誌未確認のため初出確定には不採用。
- 国芳『相馬の古内裏』＝江戸時代のがしゃどくろ、という短絡: 不採用。
- 垢嘗＝垢ねぶりの無条件同一視: 不採用。
- 木霊＝山びこ現象＝石燕木魅の単一生態化: 不採用。
- 山姥＝人食い、または山姥＝助力神という単一定義: 不採用。
